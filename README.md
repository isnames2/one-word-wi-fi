Entry for the make.fun bounty [One Word for Your Wi-Fi](https://make.fun/bounty/u-tuan-muda-one-word-for-your-wi-fi-a1b4fd72): exactly one word describing home Wi-Fi.

The word is **"Moody"** — Wi-Fi works when it feels like it, and sulks when it doesn't.

`main.py` (pure Python standard library) writes that single word to `$MAKEFUN_OUTPUT_DIR/entry.txt`.
